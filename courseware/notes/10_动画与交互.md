# 10 · 动画与交互

动画 = 每帧更新状态 + 清屏 + 重绘。交互 = 事件回调更新参数并触发重绘。

## 渲染循环

```js
function tick() {
  update();                      // 1. 更新状态
  draw();                        // 2. 清屏 + 重绘
  requestAnimationFrame(tick);   // 3. 请求下一帧
}
tick();
```

## 基于时间的动画（帧率无关）

直接每帧 `angle += 1` 会随帧率变化，应乘每帧耗时：

```js
let ANGLE_STEP = 45.0;   // 度/秒
let g_last = Date.now();
function animate(angle) {
  let now = Date.now();
  let elapsed = now - g_last;   // 毫秒
  g_last = now;
  return (angle + ANGLE_STEP * elapsed / 1000.0) % 360;
}
```

## 键盘交互

```js
document.onkeydown = function(ev) {
  if (ev.key === 'ArrowLeft')  x -= 0.1;   // 方向键
  if (ev.key === 'w')          z += 0.1;   // WASD
};
```

## 鼠标交互

```js
// 点击
canvas.onmousedown = function(ev) { click(ev); };
// 拖动（按下→移动→松开）
let dragging = false;
canvas.onmousedown = function() { dragging = true; };
document.onmouseup = function() { dragging = false; };
document.onmousemove = function(ev) {
  if (dragging) { yaw += ev.movementX * s; pitch -= ev.movementY * s; }
};
// 滚轮
canvas.addEventListener('wheel', function(e) { e.preventDefault(); /* 调 fov 等 */ }, { passive: false });
```

## UI 控件

```js
let slider = document.getElementById('angle');
slider.oninput = function() {
  let v = parseFloat(slider.value);
  modelMatrix.setRotate(v, 0, 0, 1);
  gl.uniformMatrix4fv(u_ModelMatrix, false, modelMatrix.elements);  // CPU→GPU
  draw();
};
```

颜色十六进制 ↔ RGB 转换：

```js
function hexToRgb(hex) {
  return [parseInt(hex.slice(1,3),16)/255, parseInt(hex.slice(3,5),16)/255, parseInt(hex.slice(5,7),16)/255];
}
```

## 参数从 CPU 传到 GPU 的链路

```
用户操作 → 事件回调 → 更新 JS 变量 → gl.uniform*/vertexAttrib* → 着色器 → 重绘
```
