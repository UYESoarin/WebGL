# 09 · 光照模型

光照让物体产生立体感。局部光照把颜色分解为三个分量：

```
最终颜色 = 环境光 + 漫反射 + 镜面反射
           Ambient   Diffuse    Specular
```

| 分量 | 含义 |
|------|------|
| 环境光 | 无方向均匀照明，防止背光面全黑 |
| 漫反射 | 粗糙表面向四周散射，与光线-法线夹角有关 |
| 镜面反射 | 光滑表面高光，与视线方向有关 |

## 光源类型

| 光源 | 特征 |
|------|------|
| 平行光 | 方向固定、无衰减（用方向向量表示，齐次 w=0） |
| 点光源 | 位置固定、向四周辐射，随距离衰减（w=1） |
| 聚光灯 | 位置+朝向+截止角，锥形范围内才照亮 |

## 漫反射（Lambert）

```glsl
float diffuse = max(dot(N, L), 0.0);   // N 法线，L 指向光源，夹角越小越亮
```

## 镜面反射（Blinn-Phong 半角向量）

```glsl
vec3 H = normalize(L + V);                              // 半角向量
float spec = pow(max(dot(N, H), 0.0), shininess);       // shininess 高光系数
```

Blinn-Phong 用半角向量 H 替代 Phong 的反射向量 r，无需计算 r，更高效。

## 距离衰减

```glsl
float att = 1.0 / (1.0 + a*d + b*d*d);   // 平方反比衰减；聚光灯可用较弱线性衰减保证亮度
```

## 聚光截止

```glsl
float cosTheta = dot(normalize(表面→光源), normalize(聚光朝向));
float spot = step(cutoff, cosTheta);   // 硬边缘；smoothstep 可做软边缘
```

## 法线矩阵

法向量经模型变换后可能不再垂直表面，需用**模型矩阵的逆转置**变换：

```js
normalMatrix.setInverseOf(modelMatrix);
normalMatrix.transpose();
```

## 逐顶点 vs 逐片元

| 方式 | 计算位置 | 效果 |
|------|----------|------|
| 逐顶点（Gouraud） | 顶点着色器 | 便宜，块状感 |
| 逐片元（Phong 着色） | 片元着色器 | 平滑，高光更自然 |

逐片元实现：顶点着色器把世界坐标与法线经 `out` 传到片元着色器，在片元中做光照计算。

## 多光源

片元着色器对每个光源累加漫反射+镜面，再加环境光；各光源可独立开关、独立颜色，便于观察各自作用。
