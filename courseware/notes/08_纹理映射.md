# 08 · 纹理映射

纹理映射把图片贴到几何体表面。每个顶点除位置外还带纹理坐标 `(u,v)`（范围 [0,1]，(0,0) 左下、(1,1) 右上）。

## 四步流程

```
1. 顶点数据加入纹理坐标（attribute）
2. 创建纹理对象并加载图片（Image）
3. 设置纹理参数（过滤/包裹）
4. 片元着色器用 texture() 采样
```

## 着色器

```glsl
// 顶点着色器
in vec4 a_Position; in vec2 a_TexCoord; out vec2 v_TexCoord;
void main() { gl_Position = a_Position; v_TexCoord = a_TexCoord; }
// 片元着色器
uniform sampler2D u_Sampler; in vec2 v_TexCoord; out vec4 fragColor;
void main() { fragColor = texture(u_Sampler, v_TexCoord); }
```

## 加载纹理

```js
let texture = gl.createTexture();
let image = new Image();
image.onload = function() {
  gl.pixelStorei(gl.UNPACK_FLIP_Y_WEBGL, 1);   // 2D 纹理需 Y 轴反转
  gl.activeTexture(gl.TEXTURE0);
  gl.bindTexture(gl.TEXTURE_2D, texture);
  gl.texParameteri(gl.TEXTURE_2D, gl.TEXTURE_MIN_FILTER, gl.LINEAR);
  gl.texImage2D(gl.TEXTURE_2D, 0, gl.RGB, gl.RGB, gl.UNSIGNED_BYTE, image);
  gl.uniform1i(u_Sampler, 0);   // 采样器绑定纹理单元 0
};
image.src = 'texture.jpg';
```

## 纹理参数

| 类别 | 参数 | 取值 |
|------|------|------|
| 过滤 | TEXTURE_MIN_FILTER / MAG_FILTER | LINEAR（平滑）/ NEAREST（像素风） |
| 包裹 | TEXTURE_WRAP_S / T | REPEAT（平铺）/ CLAMP_TO_EDGE / MIRRORED_REPEAT |

## 纹理坐标交错存储

每顶点 `[x, y, u, v]`，stride = 4 float：

```js
let FSIZE = vertices.BYTES_PER_ELEMENT;
gl.vertexAttribPointer(a_Position, 2, gl.FLOAT, false, FSIZE*4, 0);
gl.vertexAttribPointer(a_TexCoord, 2, gl.FLOAT, false, FSIZE*4, FSIZE*2);
```

## 立方体纹理（天空盒）

`TEXTURE_CUBE_MAP` 用 6 张无缝图片，按方向向量采样：

```js
gl.bindTexture(gl.TEXTURE_CUBE_MAP, tex);
// 6 个面目标分别 texImage2D：
gl.texImage2D(gl.TEXTURE_CUBE_MAP_POSITIVE_X, 0, gl.RGB, gl.RGB, gl.UNSIGNED_BYTE, img);
// ...
gl.texParameteri(gl.TEXTURE_CUBE_MAP, gl.TEXTURE_WRAP_S, gl.CLAMP_TO_EDGE);
// 片元着色器
uniform samplerCube u_CubeSampler;
fragColor = texture(u_CubeSampler, direction);   // direction 为 vec3 方向
```

> 注意：`UNPACK_FLIP_Y_WEBGL=1` 仅用于 2D 纹理；立方体贴图须显式置 0，否则全局状态泄漏会导致天空盒上下颠倒。

## 跨域问题

以 `file://` 直接打开时加载纹理会出现跨域错误，需经本地服务器（如 VS Code Live Server）运行。
