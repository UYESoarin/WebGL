# 05 · 缓冲区对象与多顶点绘图

缓冲区对象（VBO，Vertex Buffer Object）是 GPU 中的一块内存，可一次性上传大量顶点数据供顶点着色器使用。

## 使用 VBO 五步

```
1. gl.createBuffer()              创建缓冲区对象
2. gl.bindBuffer(target, buffer)  绑定到目标
3. gl.bufferData(target, data, usage)  写入数据（类型化数组）
4. gl.vertexAttribPointer(...)    分配给 attribute 变量
5. gl.enableVertexAttribArray(...)  开启 attribute
```

```js
function initVertexBuffers(gl) {
  let vertices = new Float32Array([0.0, 0.5,  -0.5, -0.5,  0.5, -0.5]);
  let n = 3;

  let vertexBuffer = gl.createBuffer();
  gl.bindBuffer(gl.ARRAY_BUFFER, vertexBuffer);
  gl.bufferData(gl.ARRAY_BUFFER, vertices, gl.STATIC_DRAW);

  let a_Position = gl.getAttribLocation(gl.program, 'a_Position');
  gl.vertexAttribPointer(a_Position, 2, gl.FLOAT, false, 0, 0);
  gl.enableVertexAttribArray(a_Position);

  return n;
}
```

## vertexAttribPointer 参数

```js
gl.vertexAttribPointer(location, size, type, normalized, stride, offset);
```

| 参数 | 含义 |
|------|------|
| location | attribute 存储位置 |
| size | 每顶点分量个数（1~4） |
| type | 数据类型（gl.FLOAT 等） |
| normalized | 是否归一化非浮点数据 |
| stride | 相邻顶点字节数（0 = 紧凑） |
| offset | 起始偏移（字节） |

## 绘制

```js
gl.drawArrays(mode, first, count);   // 按顶点数组绘制
gl.drawElements(mode, count, type, offset);  // 按索引绘制
```

基本图元（mode）：

| mode | 含义 |
|------|------|
| gl.POINTS | 点 |
| gl.LINES / LINE_STRIP / LINE_LOOP | 线段 / 折线 / 闭合折线 |
| gl.TRIANGLES / TRIANGLE_STRIP / TRIANGLE_FAN | 三角形 / 条带 / 扇形 |

可绘制的基本图形仅点、线段、三角形；矩形=2 三角形，正方体=12 三角形。

## 索引绘制（减少重复顶点）

```js
let indices = new Uint8Array([0, 1, 2,  0, 2, 3]);   // 矩形 = 2 三角形
let indexBuffer = gl.createBuffer();
gl.bindBuffer(gl.ELEMENT_ARRAY_BUFFER, indexBuffer);
gl.bufferData(gl.ELEMENT_ARRAY_BUFFER, indices, gl.STATIC_DRAW);
gl.drawElements(gl.TRIANGLES, indices.length, gl.UNSIGNED_BYTE, 0);
```

## 交错存储（多属性）

位置与颜色等属性可存同一缓冲区，用 stride/offset 区分：

```js
// 每顶点 [x, y, r, g, b]
let FSIZE = vertices.BYTES_PER_ELEMENT;   // 4 字节
gl.vertexAttribPointer(a_Position, 2, gl.FLOAT, false, FSIZE*5, 0);      // offset 0
gl.vertexAttribPointer(a_Color, 3, gl.FLOAT, false, FSIZE*5, FSIZE*2);   // offset 2
```
