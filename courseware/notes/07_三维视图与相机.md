# 07 · 三维视图与相机（MVP 矩阵）

把 3D 物体画到 2D 屏幕需三步变换，合称 MVP：

```
物体坐标 ──模型矩阵M──► 世界坐标 ──视图矩阵V──► 相机坐标 ──投影矩阵P──► 裁剪坐标
```

顶点着色器：`gl_Position = u_MvpMatrix * a_Position`，其中 `MVP = P × V × M`。

| 矩阵 | 作用 |
|------|------|
| 模型矩阵 M | 摆放物体（平移/旋转/缩放） |
| 视图矩阵 V | 放置相机（位置+朝向） |
| 投影矩阵 P | 定义视野范围（透视/正交） |

## 视图矩阵 setLookAt

```js
viewMatrix.setLookAt(eyeX, eyeY, eyeZ,    // 相机位置
                     atX,  atY,  atZ,     // 看向的目标点
                     upX,  upY,  upZ);    // 上方向（常 0,1,0）
```

默认相机在原点、看向 -z。漫游=移动 eye，环视=改变 at（由朝向角算出）。

## 投影矩阵

```js
// 透视（近大远小）
projMatrix.setPerspective(fov, aspect, near, far);   // fov 垂直视角，aspect 宽高比
// 正交（无透视）
projMatrix.setOrtho(left, right, bottom, top, near, far);
```

## 深度测试（消隐）

```js
gl.enable(gl.DEPTH_TEST);
gl.clear(gl.COLOR_BUFFER_BIT | gl.DEPTH_BUFFER_BIT);   // 每帧同时清颜色+深度
```

不开启深度测试会导致后绘制的物体覆盖先绘制的（遮挡错误）。

## 组装 MVP

```js
mvpMatrix.set(projMatrix).multiply(viewMatrix).multiply(modelMatrix);  // P×V×M
gl.uniformMatrix4fv(u_MvpMatrix, false, mvpMatrix.elements);
```

## 相机模型

| 模型 | 公式 | 用途 |
|------|------|------|
| 轨道 Orbit | `eye = target + r·(cosφcosθ, sinφ, cosφsinθ)` | 绕目标旋转观察 |
| 自由漫游 Fly | `forward = (−sinθ·cosφ, sinφ, −cosθ·cosφ)` | WASD 移动 + 鼠标环视 |
| 跟随 Follow | `eye = target − forward·d + up·h` | 跟拍移动物体 |

漫游中，forward 与 right 向量：

```js
forward = (sin(yaw)cos(pitch), sin(pitch), -cos(yaw)cos(pitch))
right   = (cos(yaw), 0, sin(yaw))
```

## 立方体

正方体 8 顶点、6 面、12 三角形，用 `drawElements` 复用顶点；可开启背面剔除 `gl.enable(gl.CULL_FACE)`（默认剔除背面）。
