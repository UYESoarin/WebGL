# 11 · 高级技术

综合项目常用进阶技术，按需查阅。

## 帧缓冲对象 FBO（离屏渲染 → 后期处理）

把画面渲染到纹理而非屏幕，再对纹理做后期处理（模糊、反色、折射、反射、阴影等）。

```js
let fbo = gl.createFramebuffer();
gl.bindFramebuffer(gl.FRAMEBUFFER, fbo);

let texture = gl.createTexture();
gl.bindTexture(gl.TEXTURE_2D, texture);
gl.texImage2D(gl.TEXTURE_2D, 0, gl.RGBA, W, H, 0, gl.RGBA, gl.UNSIGNED_BYTE, null);
gl.framebufferTexture2D(gl.FRAMEBUFFER, gl.COLOR_ATTACHMENT0, gl.TEXTURE_2D, texture, 0);

let depth = gl.createRenderbuffer();
gl.bindRenderbuffer(gl.RENDERBUFFER, depth);
gl.renderbufferStorage(gl.RENDERBUFFER, gl.DEPTH_COMPONENT16, W, H);
gl.framebufferRenderbuffer(gl.FRAMEBUFFER, gl.DEPTH_ATTACHMENT, gl.RENDERBUFFER, depth);

gl.checkFramebufferStatus(gl.FRAMEBUFFER) === gl.FRAMEBUFFER_COMPLETE;  // 校验
gl.bindFramebuffer(gl.FRAMEBUFFER, null);   // 解绑 = 渲染回屏幕
```

两遍渲染：先渲染场景到 FBO，再用全屏四边形 + 后期着色器采样 FBO 纹理。

## 混合（透明）

```js
gl.enable(gl.BLEND);
gl.blendFunc(gl.SRC_ALPHA, gl.ONE);                      // 加法混合（发光粒子）
gl.blendFunc(gl.SRC_ALPHA, gl.ONE_MINUS_SRC_ALPHA);      // 常规透明
```

## 粒子系统

大量小图元模拟星空、火焰、鱼群、雨雪。核心：每个粒子记录位置/速度/大小/寿命，每帧更新，用贴图四边形 + 混合绘制。

```js
function Particle() { this.position=[0,0,0]; this.velocity=[0,0,0]; this.alpha=1; this.life=100; }
function update(p) { p.position[0]+=p.velocity[0]; p.alpha-=0.05; if(p.alpha<=0) reset(p); }
```

## 雾

片元着色器按距离混合雾色：

```glsl
float fogFactor = clamp((u_FogEnd - dist) / (u_FogEnd - u_FogStart), 0.0, 1.0);
fragColor = mix(u_FogColor, originalColor, fogFactor);
```

## 投影阴影（平面投影）

沿光方向把物体顶点投影到地面，绘制为半透明黑：

- 阴影矩阵（平行光投影到 y=groundY）：

```
[ 1   -dx/dy  0   (dx/dy)·groundY ]
[ 0    0      0   groundY         ]
[ 0   -dz/dy  1   (dz/dy)·groundY ]
[ 0    0      0   1               ]
```

- 阴影 MVP = P × V × 阴影矩阵 × 模型矩阵；绘制时关闭深度写入、开启混合，略高于地面避免 z-fighting。

> 更真实的阴影用阴影映射（shadow map）：先从光源视角渲染深度到 FBO，再比较深度判断遮挡。

## 拾取、文字、模型加载

- 拾取：颜色编码或数学射线判断鼠标选中物体。
- 文字/HUD：文字纹理或 2D Canvas 生成贴图。
- 模型加载：解析 OBJ 文件（顶点/法线/纹理坐标/面）。
