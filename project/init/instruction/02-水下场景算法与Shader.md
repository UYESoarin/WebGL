# 02｜水下场景：鱼群算法、光束、焦散与水体氛围

## 学习目标

水下场景由多个独立效果叠加而成，不是一个“水下 Shader”。建议按鱼群 → 地形生态 → 水色雾化 → 光束 → 焦散的顺序实现。

## 1. 鱼群：Boids 三规则

Boids 是一种局部规则驱动的群体运动模型。每条鱼只观察邻域内的其他鱼，计算三个 steering 向量：

### 1.1 Separation（分离）

邻居距离过近时远离邻居，避免重叠。对邻居差向量按距离加权累加，再归一化。

### 1.2 Alignment（对齐）

计算邻域平均速度，让个体速度逐渐朝平均方向调整。

### 1.3 Cohesion（聚合）

计算邻域平均位置，让个体朝群体中心靠近。

组合形式可写为：

\[
\mathbf{a}=w_s\mathbf{S}+w_a\mathbf{A}+w_c\mathbf{C}+w_b\mathbf{B}
\]

其中 S/A/C 分别代表分离、对齐、聚合，B 可选表示边界回避；权重由实验调节。每帧使用 deltaTime 更新速度和位置，并限制最大速度、最大转向力。

### 1.4 初学者实现顺序

1. 先用 10 条鱼沿圆形路径运动，验证模型朝向。
2. 增加轻微正弦扰动，形成波浪队形。
3. 再实现 Boids，先用 20–40 条鱼做 O(N²) 邻居遍历。
4. 鱼数增大后，采用空间网格/空间哈希，只检查附近 cell，降低邻域查询成本。
5. 最后用 InstancedMesh 绘制鱼体；每帧更新 instanceMatrix，避免每条鱼单独一个 draw call。

注意：Boids 计算和绘制是两件事。先用 CPU 数组计算位置/速度，再用 InstancedMesh 绘制；若数量极大再考虑 GPU simulation。

### 1.5 三种模式

- School：Boids 分离/对齐/聚合。
- Orbit：绕中心切向运动，径向误差用弹性/steering 拉回环带。
- Wave：沿路径推进，横向偏移 `y = A * sin(k * s - omega * t + phase)`。

## 2. 水下雾化与颜色吸收

水体会吸收和散射光，远处对比度下降，颜色逐渐偏向水体色。简化的 Beer–Lambert 吸收可写为：

\[
T(d)=e^{-\sigma d}
\]

其中 d 是光程距离，σ 是吸收系数。可用 `mix(surfaceColor, waterColor, 1.0 - T)` 做视觉近似。MVP 可先使用 Fog；深入时再用深度信息和 Shader 近似距离相关吸收。要说明普通 Fog 不是完整水下散射模型。

## 3. 丁达尔光束（体积光近似）

真实体积光需要沿视线积分散射贡献，成本较高。本项目先做可控近似：

1. 用圆锥/平面表示光束空间范围。
2. 在 fragment shader 中根据 UV 到光束中心的距离计算软边：中心亮、边缘衰减。
3. 用噪声纹理轻微扰动亮度/边界，避免完全机械的形状。
4. 根据深度或世界高度做衰减；透明度保持较低。
5. 处理透明排序、depthWrite 和双面渲染问题。

软边示意：`beam = 1.0 - smoothstep(innerRadius, outerRadius, radialDistance)`。再乘以强度、噪声和距离衰减。

注意透明物体常见问题：排序错误、叠加过亮、穿透遮挡。不要简单把所有透明光束 `depthWrite=false` 后就认为正确，必须观察不同视角。

## 4. 焦散 Caustics

焦散是水面波动导致光线聚焦，在海底形成动态亮斑。课程项目可以使用两层滚动噪声纹理近似：

- 两张不同缩放/方向/速度的噪声或焦散纹理；
- UV 随时间沿不同方向移动；
- 纹理相乘或叠加形成变化图案；
- 通过亮度阈值和 smoothstep 提取亮斑；
- 乘以海底材质颜色和光照强度。

先用一张平铺纹理滚动，再加第二层和扰动。若没有合适贴图，可程序生成低频噪声作为过渡，但它不等同于物理焦散。

## 5. 气泡与悬浮粒子

每个粒子维护 position、velocity、lifetime。气泡向上运动并叠加水平噪声；到达上界或生命周期结束时重置。少量粒子可 CPU 更新，数量上升后使用 Points/InstancedMesh，进一步可改为 GPU 粒子。

## 6. 水下参数面板建议

| 参数 | 建议范围 | 影响 |
|---|---:|---|
| fishMode | school/orbit/wave | 切换运动模型 |
| fishCount | 10–200 | 实例数量与性能 |
| fishSpeed | 0.1–3.0 | 最大速度/时间缩放 |
| cohesionWeight | 0–3 | 群体聚合程度 |
| beamIntensity | 0–2 | 光束强度 |
| fogDensity | 0–0.15 | 远景衰减 |
| causticsSpeed | 0–2 | 焦散滚动速度 |

参数范围要根据实际场景尺度调整，不能机械照搬。

## 7. 推荐实施顺序与验收

- [ ] 海底地形有前中远景层次。
- [ ] 至少一种鱼群运动方式稳定，鱼头朝向运动方向。
- [ ] 三种鱼群模式能观察出差异（进阶）。
- [ ] 鱼群数量变化真实影响实例数量。
- [ ] 光束软边、强度可调，透明排序可接受。
- [ ] 焦散纹理有动态变化且不会明显闪烁。
- [ ] 粒子数量受控，低画质可减少。
- [ ] 记录 O(N²) 与空间分桶的差异（如实现）。

## 8. 需要理解的图形学关键词

Boids、steering behavior、邻域搜索、空间哈希、InstancedMesh、Beer–Lambert law、透明混合、depthWrite、smoothstep、UV scrolling、噪声纹理、体积散射近似。
