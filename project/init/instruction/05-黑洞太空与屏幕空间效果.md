# 05｜黑洞与太空：吸积盘、极坐标与引力透镜近似

## 1. 先区分科学概念和视觉表达

黑洞不是一个发光球体。视觉呈现通常包含暗色事件视界、周围吸积盘、背景星场被引力透镜偏折的效果。项目可做科学启发式近似，但不能称为完整广义相对论求解。

## 2. 星空与星云

- 星空使用多层 Points：远景小而暗，近景少量较亮星点。
- 生成位置尽量分布在球壳/视野范围内，避免明显平面感。
- 星云先用低透明度贴图或程序噪声平面构成；控制颜色层次，不要盖过黑洞主体。

## 3. 吸积盘

初级版本：倾斜 Torus/环带，设置 emissive 或 MeshBasicMaterial，绕中心缓慢旋转。

Shader 深化：在片元阶段把 UV 转成极坐标：
- `r = length(uv - center)`；
- `angle = atan(y, x)`；
- 使用 r 控制内外环亮度；
- 使用 angle 和 time 推动旋转纹理；
- 使用噪声扰动亮度和边缘；
- 内缘/外缘通过 smoothstep 衰减。

吸积盘不是均匀发光圆环。可以让靠近内缘更亮，外缘逐渐衰减，并叠加沿角度方向的纹理流动。

## 4. 引力透镜的屏幕空间近似

屏幕空间扭曲的思路：对屏幕 UV 根据到黑洞投影中心的距离做偏移，再用偏移后的 UV 采样背景颜色。

简化形式：
- `delta = uv - center`；
- `r = length(delta)`；
- `falloff = strength / (r*r + epsilon)`，并用 smoothstep 限制影响半径；
- `warpedUV = uv + normalize(delta) * falloff`（方向和符号需通过画面实验确认）；
- 对 warpedUV 做边界 clamp，防止采样越界。

这是屏幕空间视觉扭曲，不是光线追踪，也不是真实引力场积分。要让星点/背景可被扭曲，需要先有可采样的场景颜色纹理；仅对黑洞模型自身写 fragment shader 不会自动得到完整场景背景。

实现复杂度较高，建议作为 P1/P2。若时间不足，用吸积盘 Shader + 星场层次完成视觉中心即可。

## 5. 粒子和喷流

星尘可以 Points 或 InstancedMesh；粒子有速度、生命周期和颜色/大小变化。喷流可用锥体、曲线粒子或透明带状几何体近似。

## 6. 参数面板

- diskRotationSpeed：吸积盘旋转速度；
- diskEmission：发光强度；
- starDensity：星点数量；
- lensStrength：透镜扭曲强度（仅当实现屏幕空间 pass）；
- dustSpeed：星尘速度。

## 7. 验收

- [ ] 黑洞中心保持暗，吸积盘形成明显环绕结构。
- [ ] 吸积盘有旋转或流动细节。
- [ ] 星场有远近层次且不过度抢焦点。
- [ ] 参数能实时影响对应效果。
- [ ] 如实现透镜，需明确它是屏幕空间近似，并测试 UV 边界。
