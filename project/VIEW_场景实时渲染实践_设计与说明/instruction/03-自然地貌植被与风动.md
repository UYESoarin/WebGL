# 03｜自然场景：程序化地形、植被分布、风场与大气

## 1. 地形高度场

最直观的地形表示是规则网格：顶点的 x/z 表示地面坐标，y 表示高度 `h(x,z)`。可先用正弦和高斯山体验证，再使用噪声。

### 1.1 多频噪声 / FBM

分形布朗运动（FBM）将多层不同频率、振幅的噪声叠加：

\[
FBM(p)=\sum_{i=0}^{n-1} a_i N(f_i p),\quad a_i=a_0\lambda^i,\quad f_i=f_0\mu^i
\]

低频决定大地形轮廓，高频增加细节。振幅衰减和频率增长比例决定地形粗糙度。不要一开始堆很多 octave；2–5 层足以做初版。

### 1.2 地表材质混合

可以用高度和坡度决定草/岩/雪：
- 低高度且坡度小：草地；
- 坡度大：岩石；
- 高海拔：雪或浅色岩层。

坡度可由法线与世界向上方向点积得到：`slope = 1.0 - dot(normal, up)`。使用 smoothstep 在材质边界柔和混合。MVP 先用 vertex colors 或多材质色带，之后再加贴图混合。

## 2. 植被分布

不要在整个平面均匀随机撒树。先定义规则：
- 根据高度范围排除不适宜区域；
- 根据坡度限制树木生成；
- 通过 density map/噪声决定局部密度；
- 设定森林边缘、草地中心和河道留白；
- 用随机种子保证每次生成结果稳定。

重复树木、草丛应优先 InstancedMesh。每个实例随机化旋转、缩放和少量色差，但避免过度随机导致风格不统一。

## 3. 风动 Shader

风动的关键不是让整棵树刚体旋转，而是让枝叶顶部位移大、树干根部位移小。

顶点位移思路：

1. 获取顶点世界位置或模型空间高度。
2. 用高度归一化得到权重 `w = smoothstep(rootHeight, tipHeight, vertexHeight)`。
3. 根据风向 `windDir` 计算投影位置。
4. 用时间和空间相位生成波动：`wave = sin(dot(position.xz, windDir) * frequency - time * speed)`。
5. 位移：`offset = windDir * wave * amplitude * w`。
6. 叠加低频噪声，避免所有树同步摆动。

关键点：模型 pivot、坐标空间和法线处理。若顶点位移较大，法线可能不再准确；初版可接受轻微近似，进阶需重新计算或采用简化光照。

## 4. 天空与大气

MVP：渐变天空/天空盒 + Fog。风格化场景重点是天空色、太阳方向、雾色和远景山体颜色统一。

进阶：Sky Shader / 大气散射近似。大气效果可从 Rayleigh/Mie 散射概念理解：短波长散射更强、太阳方向和观察方向影响天空颜色。课程实现不要求完整物理模型，可通过参数化天空渐变和雾色得到风格化效果。

## 5. 可选水体

湖泊/河流可以从平面 + 两层法线纹理滚动开始。Fresnel 近似用于控制掠射角反射增强：视线越贴近表面，反射越强。先理解 `dot(viewDir, normal)` 与 `pow(1 - NdotV, power)` 的关系，再尝试水面 Shader。

## 6. 参数面板

- windStrength：风动幅度；
- windSpeed：风速；
- vegetationDensity：植被密度；
- terrainRoughness：地形粗糙度（若支持实时重建）；
- fogDensity：雾浓度；
- timePreset：清晨/正午/黄昏。

实时修改地形网格可能需要重建 geometry，成本较高；MVP 可以只调材质和风动参数，地形生成参数放在初始化配置。

## 7. 验收

- [ ] 地形有山体、谷地和可辨识地面层次。
- [ ] 植被分布遵循区域规则，不是均匀撒点。
- [ ] 风动根部稳定、顶部摆动明显。
- [ ] 多棵树有相位差，不完全同步。
- [ ] 雾色与天空色协调，远景层次清晰。
- [ ] 植被数量增加时优先实例化，不造成 draw call 爆炸。
