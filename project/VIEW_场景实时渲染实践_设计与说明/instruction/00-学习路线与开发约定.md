# 00｜学习路线与开发约定

## 1. 你的现有基础与学习目标

你已经接触过 Unity Shader，并能编写基础 Shader。因此不需要从“什么是顶点/片元着色器”完全从零开始，但要把 Unity 的 Shader 思维迁移到 WebGL / Three.js：理解坐标空间、材质管线、uniform、buffer、纹理采样、透明混合、深度测试、后处理和 GPU 性能。

学习目标不是记住一段 GLSL，而是能够回答：
- 效果由哪些视觉现象构成？
- 哪些部分用现成 Three.js 功能即可，哪些必须自定义 Shader？
- 算法的输入、状态、计算步骤和输出是什么？
- 哪些计算在 CPU，哪些在 GPU？
- 参数变化会影响什么？性能瓶颈在哪里？

## 2. 学习节奏

每个效果按五步完成：
1. **观察拆解：** 找参考图/视频，拆出空间、材质、光照、动画、后处理。
2. **低成本复现：** 用基础几何体、标准材质和少量对象先复现构图。
3. **算法实现：** 明确数学模型或行为规则，再写代码。
4. **Shader 深化：** 只有 CPU/材质方案不足时才写 GLSL。
5. **测量与解释：** 记录参数、视觉变化、帧时间和实现限制。

每个效果建议保留一个 `effect-notes.md`：原理、算法、关键参数、代码入口、已知问题、优化方向。

## 4. Unity Shader 到 Three.js 的概念映射

| Unity 常见概念 | Three.js / WebGL 对应 |
|---|---|
| Material / Shader Graph | Material / ShaderMaterial / NodeMaterial（本项目先不用 NodeMaterial） |
| Properties | uniforms / material 参数 |
| Vertex Shader | vertexShader |
| Fragment Shader | fragmentShader |
| Mesh Renderer | Mesh + Material |
| Render Texture | WebGLRenderTarget / 后处理 pass |
| Camera Depth Texture | 深度纹理/深度缓冲相关能力，需自行配置和验证 |
| Post Processing Volume | EffectComposer / R3F postprocessing |
| GPU Instancing | InstancedMesh |

注意：Three.js 的 `ShaderMaterial` 默认提供部分内建 attribute/uniform；`RawShaderMaterial` 更接近完全自定义管线，但初学阶段优先 ShaderMaterial。Three.js 版本升级可能改变 shader chunk，避免依赖未经确认的内部 chunk。
